# Homework (Simulation)
The program relocation.py allows you to see how address translations are performed in a system with base and bounds registers. 

Equation:
  physical address = virtual address + base
Key flags:
-s = random seed
-a = address space size (default 1k)
-p = physical memory size (default 16k)
-n = number of virtual addresses to generate
-b = manually set base register (otherwise randomized)
-l = manually set limit/bounds register (otherwise randomized)
-c = compute/reveal answers
